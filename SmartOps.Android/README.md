# SmartOps Survey — Android app

This folder contains the **SmartOps Survey Android APK** (`com.smartops.apk`), a ready-to-install mobile application for testing the SmartOps 4D integration.

The app allows field operatives to download jobs, complete surveys, record information and upload photographs through the SmartOps 4D API.

## Installation

1. Download [com.smartops.apk](./com.smartops.apk) to your Android phone or tablet.
2. Open the downloaded file on the device.
3. If Android prompts you, allow **Install unknown apps** for the browser or file manager you used.
4. Confirm **Install**, then open **SmartOps Survey**.

The app is also available on [Google Play](https://play.google.com/store/apps/details?id=com.authorityx.smartops).

## Connecting to SmartOps

To download and upload jobs, the app must be configured to connect to a running SmartOps 4D API. See the [SmartOps repository README](../README.md) for integration kit setup information.

**Note:** Installing an APK outside Google Play may trigger a standard Android security prompt. Only install files from a source you trust.
