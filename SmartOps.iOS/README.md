# SmartOps Survey — iOS unsigned device builds

This folder contains the unsigned iOS device builds of the SmartOps Survey App:

- `SmartOps-iOS-net11-unsigned.ipa` — an unsigned iOS ARM64 package
- `SmartOps-iOS-net11-unsigned-app.zip` — an unsigned `.app` archive for developers

These files require **Apple code signing and provisioning** before installation on an iPhone or iPad. They are not App Store downloads and cannot be installed directly like the Android APK.

For signing and installation requirements, see [README-iOS.txt](../packaging/ios/README-iOS.txt).
