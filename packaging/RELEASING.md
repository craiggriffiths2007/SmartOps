# SmartOps integration kit

The complete, prebuilt SmartOps integration kit is available from the [GitHub Releases page](https://github.com/craiggriffiths2007/SmartOps/releases).

The repository's `packaging/` folder contains supporting instructions and build resources used to assemble that downloadable release. You do **not** need to run the packaging scripts to use the kit.

The downloadable release contains the 4D integration project, optional Windows web application, Android APK, unsigned iOS build files (requiring Apple signing), and API documentation.

Release automation is maintained privately. Users of the integration kit should follow the [project README](../README.md) and the instructions contained in the release ZIP.
